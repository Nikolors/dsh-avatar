# DSH Avatar — живое лицо для DeepSeek Harness на Windows

Аватар-компаньон для [DeepSeek Harness](https://github.com/deepseek-ai): отдельное
окно с лицом, которое говорит вместе с голосовым ответом. Без видеокарты, без
нейросетей в реальном времени — только заранее нарезанные ролики и аккуратная
синхронизация со звуком.

[Видео в лучшем качестве (MP4, 1,4 МБ)](demo/demo.mp4) · [Скриншот](docs/screenshot.png)

Английская версия: [README.en.md](README.en.md).

Сделано для старого ноутбука: видеокарта занята другими задачами, поэтому лицо
«играется» из готовых роликов, а не рисуется нейросетью на ходу.

## Что умеет

- **Окно с лицом поверх остальных** — без рамки, с прозрачным фоном, всегда сверху.
- **Цельный ролик на реплику** — ответ играется одним куском: покой, речь, снова
  покой. Между фразами нет пересборки и заметных стыков.
- **Общий кадр покоя** — все ролики начинаются с одного и того же кадра, поэтому
  вход из статики совпадает один в один, без перекрёстного затухания.
- **Синхронизация со звуком** — кадры начинаются по событию «озвучка пошла», темп
  ролика ограничен, чтобы не мелькал на коротких фразах и не тянулся на длинных.
- **Покой** — тот же общий кадр с лёгким дыханием, когда ассистент молчит.
- **Сторож служб** — следит за распознаванием, озвучкой, окном и мостом,
  перезапускает только упавшее звено и пишет журнал.
- **Автоматические точки возврата** — ежедневная и перед рискованными правками.

## Как это устроено

```
микрофон → распознавание (локально) → DSH → ответ
                                            │
                                    озвучка (edge-tts)
                                            │
                                     мост (tts_bridge.py)
                                            │
                                  окно с лицом (call_live.py)
```

Окно не занимается звуком: оно читает журнал плагина и очередь файлов, выбирает
ролик под длину реплики и показывает кадры 25–50 раз в секунду.

## Состав

| Файл | Что делает |
|---|---|
| `avatar/call_live.py` | окно с лицом: показ роликов, покой, синхронизация |
| `avatar/tts_bridge.py` | мост между приложением и очередью файлов озвучки |
| `avatar/watchdog.py` | сторож служб |
| `avatar/backup_day.py` | точки возврата |
| `clips-maker.py` | нарезка клипов из аудио |
| `tools/render_films.py` | рендер роликов моделью Ditto (тишина — фраза — тишина) |
| `tools/cut_films.py` | нарезка роликов в кадры окна (320×374, 50 к/с) |
| `tools/pick_idle.py` | выбор самого спокойного участка для покоя |
| `tools/clip_profiles.py` | профили рта по роликам |
| `tools/interp_clips.py` | интерполяция кадров до 50 к/с |

## Требования

- Windows 10/11, Python 3.12 (в репозитории используется venv).
- DeepSeek Harness с включённым голосовым режимом и озвучкой.
- Набор клипов в `avatar/_clips/talk_XX/*.jpg` (в репозиторий не входят —
  клипы делаются из своего портрета).

## Установка (коротко)

1. Скопировать `avatar/` в рабочую папку DSH.
2. Указать пути в начале файлов: рабочая папка, папка `dsh-voice`, порт озвучки.
3. Запустить `call_live.py` через планировщик задач (pythonw, при входе).
4. Положить клипы и один портрет в `avatar/`.
5. Проверить: включить голосовой режим, сказать фразу.

Подробная инструкция — в [docs/установка.md](docs/установка.md), про клипы — в [docs/clips.md](docs/clips.md).

## Ограничения

- Клипы не знают слов: совпадает только длина и общее настроение, мимика под
  конкретные звуки не подстраивается.
- Нужен DeepSeek Harness: окно читает его журнал и файлы озвучки.
- Windows-only: используются WinAPI для окна и проверки видимости приложения.
