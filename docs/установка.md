# Установка

Подробно, по шагам. Всё проверено на Windows 11 и Python 3.12.

## 1. Что должно быть готово

- DeepSeek Harness с профилем `desktop`.
- Разговорный режим и озвучка (`@goodandready/dsh-voice`, `@goodandready/dsh-tts`).
- Распознавание речи локально (у нас SenseVoice/GigaAM на `127.0.0.1:6006`).
- Тёплая озвучка edge-tts (у нас воркер на `127.0.0.1:8901`).

Проверка: скажите фразу в разговорном режиме — ответ должен звучать.

## 2. Куда класть

Создайте папку `avatar` в рабочей папке DSH и скопируйте туда `call_live.py`,
`tts_bridge.py`, `watchdog.py`, `backup_day.py`.

## 3. Пути

В начале каждого файла замените условные пути на свои:

- `<WORKSPACE>` — рабочая папка DSH;
- `<DSH_VOICE>` — папка `dsh-voice`;
- `<DSH_PROFILE>` — профиль, обычно `C:\Users\<имя>\.dsh\profiles\desktop`.

## 4. Порт приложения

Приложение каждый раз слушает новый порт. Мост (`tts_bridge.py`) сам находит
его и пишет в `avatar\_origin.txt` — окно читает файл оттуда.

## 5. Клипы

Нужны папки `avatar\_clips\talk_01 ... talk_NN` с кадрами JPEG по 25 в секунду,
и один цикл покоя `avatar\_idle`.

Свои клипы делаются скриптом `clips-maker.py`: он берёт фразы из
`avatar\_call\*.wav` и рендерит видео с губами, затем раскладывает кадры.

## 6. Запуск

```cmd
schtasks /create /tn DshWindow /tr "<pythonw> \"<WORKSPACE>\avatar\call_live.py\"" /sc onlogon
schtasks /create /tn DshBridge /tr "<pythonw> \"<WORKSPACE>\avatar\tts_bridge.py\"" /sc onlogon
schtasks /create /tn DshWatchdog /tr "<pythonw> \"<WORKSPACE>\avatar\watchdog.py\"" /sc onlogon
```

Важно: запускать именно через планировщик. Процессы, поднятые из терминала,
гаснут вместе с ним.

## 7. Проверка

1. Включите разговорный режим — в плашке «Слушаю…».
2. Скажите фразу — появляется окно с лицом, губы двигаются со звуком.
3. Выключите режим — окно прячется через пару секунд.
4. Ctrl+M — микрофон гаснет, лицо остаётся.

## Если что-то не так

- **Окна нет, а режим включён.** Смотрите `avatar\_live.log`: если строки
  идут, а окна нет — оно уехало за край экрана (в новых версиях окно
  возвращается само).
- **Окно есть, губы не двигаются.** Проверьте `avatar\_bridge.log`: он должен
  писать «подключение к http://127.0.0.1:<порт>».
- **Фразы идут, но поздно.** Смотрите `avatar\_live.log`: время в строке
  «фраза uNN.wav» должно совпадать с началом звука.
